# Nihongo Learn 🎌

Nihongo Learn, Türkçe konuşanlar için modernize edilmiş, görsel odaklı ve bilimsel temelli bir Japonca öğrenme platformudur.

## 🚀 Vizyon
Kullanıcıların Japonca alfabelerini (Hiragana, Katakana) ve günlük kelimeleri, animasyonlu flashcardlar ve SM-2 (Spaced Repetition) algoritması yardımıyla en verimli şekilde öğrenmesini sağlamak.

## ✨ Temel Özellikler
- **SM-2 Algoritması:** Unutma eğrisine karşı kişiselleştirilmiş tekrar aralıkları.
- **Görsel Hafıza:** Her karakter ve kelime için özenle tasarlanmış illüstrasyonlar.
- **Dinamik Quizler:** Öğrenilen bilgileri pekiştiren interaktif sınavlar.
- **Modern Teknik Stack:** Next.js 14, Tailwind CSS, Zustand ve Framer Motion.
- **Bulut Senkronizasyonu:** Supabase ile tüm cihazlarda verileriniz güvende (Faz 2).

## 🛠 Teknik Kurulum

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```

## 📅 Yol Haritası
- **Faz 1 (MVP):** Hiragana, Local SM-2 Engine, Dashboard. (Şu an buradayız 📍)
- **Faz 2:** Katakana, Supabase Auth & DB, Bulut Senkronizasyonu.
- **Faz 3:** Ses Entegrasyonu (TTS) ve PWA Desteği.
- **Faz 4:** N5 Kanji ve Günlük Hatırlatıcılar.
